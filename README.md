# Nobel Laureate Data Dashboard

An extensive dashboard (or collection of visualizations) with regard to Nobel Laureates and Nobel Prizes, based on Plotly & Dash.
Head to www.nbldata.org for a live demo.

The main files are app.py (which runs the Dash/Flask app, and contains the layout and the filter logic), and plotdatagenerator.py (which contains alle the functions for filtering and generating the plots).
